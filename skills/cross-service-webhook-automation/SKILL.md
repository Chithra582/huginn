# Cross-Service Webhook Automation Skill

Connects external web services into automated agent workflows.

## Core Capabilities
- Authenticates and validates incoming webhooks (Slack, GitHub, Stripe).
- Dispatches outgoing HTTP POST/PUT requests with custom headers.
- Formats payloads into destination-specific message schemas.
