# Web Scraping and Feed Monitoring Skill

Continuously extracts and monitors web resources for data changes.

## Core Capabilities
- Scrapes structured data from HTML pages using XPath and CSS selectors.
- Normalizes RSS/Atom feed items into standardized event payloads.
- Emits events only when content diffs exceed novelty thresholds.
