# Event Pipeline Orchestration Skill

Directs structured event flows across multi-agent scenarios.

## Core Capabilities
- Connects emitter and receiver agents in directed acyclic graphs.
- Transforms payloads using Liquid templating and JSONPath expressions.
- Guarantees event delivery with transactional database commits.
